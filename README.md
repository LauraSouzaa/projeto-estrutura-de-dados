# projeto-estrutura-de-dados

## Estrutura do projeto

- `main.py`: programa principal.
- `models/`: classes Cliente, Produto e Venda.
- `estruturas/`: LSE, LDE, Fila, Pilha e Nodo.
- `algoritmos/`: busca binária e ordenação.
- `services/`: persistência dos dados em CSV.
- `data/`: arquivos CSV utilizados pelo sistema.
